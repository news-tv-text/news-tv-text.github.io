# ТВ-ЛУНЕВО // бот ночного телетекста

Телеграм-бот к рассказу «Лампы через одну». Читает тот же `story/content.json`,
что и сайт, поэтому текст правится в одном месте: `stories/lampy-cherez-odnu.md`
→ `python3 stories/build_content.py`.

## Что умеет

- три цифры в чат — открывается страница (как на настоящем декодере);
- главы приходят в несколько сообщений с паузами, а не стеной текста;
- `/dalshe` — продолжить с непрочитанной главы;
- `/stroka` — прислать объявление из блока;
- `/noch` — ночной эфир: после полуночи по МСК бот сам присылает строку,
  которой никто не набирал (не чаще раза в сутки на человека);
- страница `214` заперта, пока не прочитаны все главы и не найдены номера
  `116`, `313`, `212` — те же правила, что на сайте;
- прогресс у сайта и бота раздельный: сайт хранит его в localStorage,
  бот — в `bot/state.json`.

## Запуск

```bash
pip install -r bot/requirements.txt
export BOT_TOKEN="123456:AA..."                       # от @BotFather
export SITE_URL="https://news-tv-text.github.io/story/"  # необязательно: кнопка «открыть декодер»
python3 bot/bot.py
```

Бот работает на long polling — нужен любой процесс, который не засыпает
(VPS, Railway, Fly.io, домашняя машина). На GitHub Pages он жить не может:
Pages отдаёт только статику.

Команды для BotFather (`/setcommands`):

```
dalshe - продолжить чтение
stroka - объявление из блока
noch - ночной эфир вкл/выкл
```

## Файлы

- `bot.py` — весь бот;
- `state.json` — прогресс читателей, создаётся сам (в git не коммитится).
